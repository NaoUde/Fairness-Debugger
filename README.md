# Fairness-Debugger
Interactive Algorithmic Fairness &amp; Explainability Debugger:   A web dashboard where developers upload a tabular dataset and a trained classification model (loan approval, hiring screening, etcetera) to visualize bias metrics and test mitigation trade-offs.

Key Features: Calculate demographic parity and equalized odds, generate SHAP/LIME feature importance explanations for individual predictions, let users apply threshold adjustments to see how fairness improvements impact overall accuracy.
Benefit: Illustrates understanding of math and policy trade-offs behind algorithmic fairness while displaying capacity of full-stack engineering.
Downside: Less display of software engineering skills, less practical functionality as a standalone tool.
